# BlockRadio 0.2.0 — общий проигрыватель

Minecraft Java 1.20.1 / Fabric Loader 0.19.3 / Java 17.
Требуется Fabric API для 1.20.1 (сборка проверяется с 0.92.2+1.20.1).

## Установка для вас двоих

1. Закройте Minecraft у обоих игроков.
2. Удалите прежний blockradio-0.1.1.jar (или 0.1.0) из mods.
3. Положите blockradio-0.2.0.jar в mods у обоих. Оставьте установленный Fabric API.
4. Каждый запускает bridge/START_WINDOWS.bat на своём компьютере и оставляет окно открытым.
5. Каждый входит в СВОЙ Яндекс через меню проигрывателя. У каждого должен быть доступ к песне.
6. Хозяин открывает мир для совместной игры обычным способом (например, Essential).
7. Оба подключаются к миру. Один нажимает ПКМ по обычному проигрывателю и выбирает песню.

Если используете отдельный выделенный сервер: установите этот же JAR и Fabric API на сервер.
Python, помощник и вход в Яндекс на выделенном сервере НЕ нужны.
При Essential встроенный сервер запускает общую часть мода из JAR хозяина.

## Что синхронизируется

- Выбор трека, пауза, продолжение, перемотка и стоп.
- Подошедший позже игрок получает текущую позицию песни после загрузки.
- Громкость плавно уменьшается с расстоянием; на 32 блоках и дальше — тишина.
- Громкость в меню личная. Также учитываются Общая громкость и Музыкальные блоки Minecraft.
- Удаление проигрывателя останавливает музыку (серверная проверка раз в секунду).
- Управление доступно игрокам возле блока; далеко отправленные команды сервер отклоняет.

Это первая многопользовательская версия: ОДИН активный проигрыватель на весь сервер.
Запуск другого заменяет текущий. Автоматической очереди нет.
Кнопки предыдущего/следующего трека переключают результаты поиска управляющего игрока.
При выгрузке чанка проигрывателя станция останавливается.
Пространственный эффект пока — громкость по расстоянию, без стереопозиционирования и стен.

## Вход и загрузка

Каждый слушатель получает аудио самостоятельно через локального помощника.
Токены/пароли не передаются серверу или другим игрокам.
Музыка зависит от доступности трека, региона и подписки каждого слушателя.
Вход: «Войти в Яндекс» → ссылка в браузере → код с локальной страницы.
Успех входа: кнопка «Статус входа» показывает ready.
После входа слушатель автоматически повторяет загрузку примерно через 10 секунд.
Первая загрузка может занять время. Синхронизация приблизительная: сеть и задержки
звукового устройства могут дать небольшое расхождение между компьютерами.
Максимальная длина — 15 минут; декодированное аудио может занимать около 80 МБ памяти.
Используется неофициальная библиотека yandex-music.

## Быстрая проверка вдвоём

1. Встаньте рядом с блоком и запустите песню.
2. Второй игрок отходит на 16, затем на 33 блока: звук должен затихать и исчезнуть.
3. Вернитесь: должна звучать текущая часть песни.
4. Проверьте паузу и перемотку с первого компьютера.
5. Сломайте блок: звук должен остановиться у обоих.
6. Если второй игрок не слышит: проверьте его помощник, статус ready и громкость
   «Музыкальные блоки». Сообщение об ошибке показывается над панелью предметов.

## Проверки перед выпуском

Смотрите VALIDATION.txt. Проверка двумя настоящими Minecraft-клиентами
и реальными аккаунтами Яндекса здесь недоступна; её нужно пройти по шагам выше.
